# 投标书生成技能

## 触发条件
当用户请求包含以下任一关键词时加载此技能:
- "生成投标" / "写投标" / "投标文件"
- "技术方案" / "商务报价" / "资格声明"
- "项目管理方案" / "售后服务方案"

## 执行流程 (必须严格按步骤)

### Step 1: 选定招标文件
- 用户给了编号/db_id → 直接用; 未提供 → **先调用 `list_bid_documents`** 列出当前账号可见招标文件, 让用户确认或自己按名称选定
- 不要凭记忆杜撰项目信息

### Step 2: 调用标书工具逐章生成
- **必须调用 `generate_bid_draft`** (参数: db_id + section), 不要自己从零撰写
- section 取值: technical(技术方案) / commercial(商务方案) / qualification(资格响应) / project_management(项目管理) / after_sales(售后服务)
- 每次调用只生成一章; 用户要多章就按章节多次调用
- 工具内部已自动完成: 招标要求提取 + RAG 同类案例检索 + 占位符防幻觉

### Step 3: 交付
- 将工具返回的 Markdown 原样呈现给用户, 用 `## 章节名` 开头
- 末尾汇总 **待补清单**: [公司全称]/[资质证书编号] 等占位符需人工替换
- 提示用户可在"文档解析"页一键导出 Word

## 禁止事项
- 不得编造具体资质证书编号、财务数据
- 不得虚构已完成案例 (可以用 "[类似项目]" 占位)
- 价格/报价必须标注为 "参考值, 以公司实际测算为准"
