# 投标书生成技能

## 触发条件
当用户请求包含以下任一关键词时加载此技能:
- "生成投标" / "写投标" / "投标文件"
- "技术方案" / "商务报价" / "资格声明"
- "项目管理方案" / "售后服务方案"

## 执行流程 (必须严格按步骤)

### Step 1: 理解招标要求
- 如果用户已上传招标文件 (有 db_id 或已解析), 先调用 `search_bidding_knowledge` 确认关键要求
- 提取: 预算金额、资质门槛、评分方法、核心标的
- **缺失关键信息时主动追问用户**, 不要瞎编

### Step 2: RAG 检索相似案例
- 调用 `search_bidding_knowledge`, query 格式:
  ```
  "{标的类型} 采购 技术方案 投标案例"
  ```
- 目标: 找 2-3 份同类项目作为参考

### Step 3: 生成章节
按章节逐一生成, 每章都要:
1. 先输出章节标题
2. 再输出内容 (300-800 字/章)
3. 标注 **[需用户填写]** 的占位符 (公司名、资质编号、具体参数)

**必须覆盖的章节**:
1. 技术方案 (核心) — 针对标的的技术实现、方案优势
2. 商务报价说明 — 报价依据、分项说明、优惠条件
3. 资格声明 — 资质声明、无违法记录、财务状况
4. 项目管理 — 项目组织架构、项目经理、里程碑计划
5. 售后服务 — 服务响应、质保期、培训方案

### Step 4: 合规检查 (可选但推荐)
生成后自查:
- 是否满足招标文件的资质要求?
- 报价是否在预算范围内?
- 是否有明显的排他性/违规表述?

### Step 5: 交付
- 输出完整草稿, 用 Markdown 格式
- 末尾列出 **待补清单**: 所有 [需用户填写] 项目汇总
- 提供导出 Word 选项

## 格式规范
- 每章开头用 `## 章节名`
- 关键条款用 **加粗**
- 表格用 Markdown 表格 (如报价明细)
- 占位符用 `[公司全称]` / `[资质证书编号]` 格式

## 禁止事项
- 不得编造具体资质证书编号、财务数据
- 不得虚构已完成案例 (可以用 "[类似项目]" 占位)
- 价格/报价必须标注为 "参考值, 以公司实际测算为准"
